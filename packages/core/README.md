# @nubisjs/core

The engine behind [Nubis](https://eytak.com/nubis): command, component and modal definitions with inferred types, guards and middleware, Discord's rules checked at definition time, and dispatch with the reply lifecycle.

Most bots should install [`nubis`](https://www.npmjs.com/package/nubis), which re-exports everything here.
